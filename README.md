# Микроэкономика

Учебный справочник с определениями, формулами, обозначениями и графиками. Темы и параграфы идут в порядке учебника. Номера страниц указывают на начало соответствующих параграфов в использованном издании.

Откройте `index.html` в браузере. GitHub Pages обслуживает сайт из корня ветки `main`. Сборка и внешние зависимости не требуются.

При открытии параграфа отображается вся его тема. На сенсорном экране потяните страницу вниз, когда она прокручена до самого верха, чтобы обновить её.

Учебный текст находится в `content.js` и `lecture-content.js`, формулы MathML — в `formulas.js`, данные графиков — в `graphs.js`.

# Микроэкономика

Учебный справочник по теме 6 «Выбор потребителя». Включает формулы, обозначения, графики и пять задач ДЗ № 4 с подсказками и решениями.

Откройте `index.html` в браузере. Для GitHub Pages сайт можно обслуживать из корня ветки `main`. Сборка и внешние зависимости не требуются.

Учебные карточки и задачи находятся в `content.js`. Номера страниц относятся к изданию из оглавления пользователя и указывают на начало соответствующих параграфов.

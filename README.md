# Микроэкономика

Учебный справочник по теме 6 «Выбор потребителя». Включает определения, формулы с расшифровкой обозначений и графики.

Откройте `index.html` в браузере. Для GitHub Pages сайт можно обслуживать из корня ветки `main`. Сборка и внешние зависимости не требуются.

Определения и формулы находятся в `content.js`. Номера страниц относятся к изданию из оглавления пользователя и указывают на начало соответствующих параграфов.
